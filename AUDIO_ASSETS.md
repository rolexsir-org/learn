# LEARN audio system and asset notes

## Audio engine

`src/services/AudioManager.ts` is the single owner for global mute, independent music/effects/voice levels, music scene lifecycle, short synthetic UI feedback, crossfades, app visibility, and persisted preferences. Music is opt-in and is never started merely by opening a screen. Story narration uses the device's Web Speech voices; only exact `en-US` and `en-GB` voices reported by the device are offered as selections. Speech volume and pace are configurable. Voice availability, quality, offline support, and recognition support depend on the OS/browser installation.

Four small, local, looping WAV tracks are generated from the source composition in `scripts/generate_audio_assets.py`; the script uses only Python's standard library and creates no network calls. Tracks are shipped in the web/native app bundle, not fetched from a third party. Playback uses HTML media elements with metadata-first preload rather than decoding all music into memory. Browser offline use depends on the browser's cached asset response; the bundled Capacitor web assets are available locally after installation.

## Platform / verification limits

The browser provides system output volume and media routing. Capacitor app foreground/background notifications pause and resume eligible music; the web layer cannot directly guarantee Android audio-focus policy or detect every incoming-call/Bluetooth route event. Real-device checks are required for audio focus, call interruption behavior, headphone routing, battery, and offline playback; no such device test is claimed by the repository change. Device TTS voices are system-provided and are not bundled/licensed by LEARN.
